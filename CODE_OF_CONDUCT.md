# Código de Conduta

Este projeto adota um código de conduta simples, adaptado do [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/) (licença CC BY 4.0).

## Nosso compromisso

Queremos que participar do projeto seja uma experiência respeitosa e livre de assédio para todas as pessoas, independentemente de idade, aparência, deficiência, etnia, identidade ou expressão de gênero, nível de experiência, nacionalidade, religião, orientação sexual ou **posicionamento político**.

Como o projeto trata de eleições, esperamos debate técnico, não disputa partidária: as discussões aqui são sobre código, dados e design.

## Comportamentos esperados

- Tratar as pessoas com respeito e empatia.
- Aceitar críticas construtivas e dar feedback de forma gentil.
- Focar no que é melhor para o projeto e para quem o usa.
- Citar fontes ao questionar um número ou uma regra de apuração.

## Comportamentos inaceitáveis

- Insultos, ataques pessoais, assédio ou discriminação.
- Divulgar informações privadas de outras pessoas.
- Propaganda eleitoral, desinformação sobre o processo eleitoral ou uso do projeto para promover ataques a candidatos ou eleitores.
- Qualquer conduta que seria considerada inadequada em um ambiente profissional.

## Aplicação

A pessoa mantenedora pode editar, ocultar ou remover comentários, *issues* e *pull requests* que violem este código, e bloquear quem o descumprir de forma reiterada.

Para relatar um problema, abra uma *issue* sem expor dados sensíveis ou entre em contato com o mantenedor pelo perfil [@Piaulucas](https://github.com/Piaulucas).
